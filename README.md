# wafelbak

Humoristische en aantrekkelijke eventsite voor de **Vliegende Wafelbak** en het
**Belgisch Kampioenschap Eland Balken**.

## Lokaal draaien

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Open daarna:

`http://127.0.0.1:4173`

## Tests

```bash
node --test tests/wafelbak.test.js
```
